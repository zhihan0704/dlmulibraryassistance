# 桌面扩展验收 1.0.0

## 已通过的代码与浏览器验证
- Manifest V3、严格TypeScript、Vite构建和权限/CSP产物检查。
- 本机Edge真实扩展API加载，使用独立测试配置和被本地拦截的合成学校页面，不使用用户真实账号。
- Element UI表头/表体分离结构中的完整预约读取；错误路由、截断编号、非法时间、冲突记录拒绝。
- 自动生成持久任务，Side Panel选择预约，用户刷卡报告保持等待核验。
- 页面明确“已签到”等文本变化才确认；审核通过和状态位不确认。
- QR本地生成、刷新后恢复、完整关闭/重启后保留任务与历史。
- 原座位读取/地图/搜索/DOM更新29项回归、旧模拟任务重启9项回归通过。

证据：evidence/extension-product-e2e.json、extension-product.png、e2e-live.txt、e2e-restart.txt。测试页面均为合成数据，截图不能作为学校真实签到证据。

## 真实环境边界
未在用户日常配置中重新安装新版并登录学校；未以鼠标实际点击原生工具栏/Side Panel；未进行校园卡现场测试。已配置openPanelOnActionClick、原生图标、Side Panel路径，自动化直接打开扩展面板文档而非证明原生按钮点击。Chrome本机未找到，未实测。学校网页结构发生变化时安全拒绝读取，需要更新适配器，不能保证所有未来页面版本。

认证状态AUTHENTICATED仅表示最近官方业务页面可读取，不证明SSO服务端永久有效。Worker重建后默认UNKNOWN；再次进入个人预约自动新观察。同源权限仅学校座位域，SSO域URL提示依赖浏览器可见信息；无法判断时保持未知/提示人工登录。无认证保活请求、无自动密码输入。

已存在桌面“海大图书馆预约助手”快捷方式，目标和绿色图标均存在，参数为官方首页。本轮调用快捷方式返回成功；未视觉核对其最终浏览器URL，因此不将该动作记为业务页就绪。见evidence/desktop-shortcut.json。
