# 1.0.0 发布判断

代码集成、严格类型检查、单元/历史安全测试、两端构建、真实Edge本地合成数据集成均通过。发行形式：可加载扩展与可HTTPS托管的静态PWA；不包含公网托管或商店发布。

软件功能可以按README安装使用，但未将真实学校账户/校园卡/手机实机验收伪装为完成。真实验收待用户在日常Edge加载新版并人工登录、部署PWA后用手机验证；现场刷卡由本人决定。学校规则冲突和服务端会话期限不受本软件控制。

仓库保留phase6-complete与phase7-complete，不重写历史。旧实验脚本修改与研究快照不归入新软件提交，也不自动导入数据库。先前阶段未完成报告留在工作区作为历史；当前发布依据本报告及本轮测试证据。
