# 1.0.0 安全审计

范围：src、mobile、两端构建、发布脚本；历史研究脚本独立保留，不进入日常启动流程。本次没有外部发布用户数据。

- 应用未读取密码输入框、Cookie或Token，无凭据持久化或复制。
- 扩展只允许目标座位域；notifications为新功能必要权限，安装升级由用户确认。
- Fetch/XHR旁路只观察同源精确GET /ic-web/reserve；保持原函数返回和请求，先在MAIN world按白名单脱敏，再缓冲和跨world传递。查询参数、姓名、账号等不进入消息。测试含跨域、POST、相似路径和身份泄漏拒绝。
- 个人记录通过匹配表头读取可见单元格，不操作按钮，不枚举接口。完整编号不固定长度；多个字段联合哈希，二维码不包含原始编号。
- 后台消息按发送者origin/frame或本扩展面板URL校验。未知操作拒绝。跨设备导入不能提升官方或认证信任。
- 交接字段严格白名单、结构上限、明确时区、有效期和系统时间检查，ICS标准CRLF且无动态换行字段注入。
- PWA无云API或分析脚本，CSP限制同源应用资源；相机仅用户点击后申请，不录音、不定位。
- 备份SHA256用于损坏检测，不是签名；恢复验证在落库前执行，保留本机官方证据，导入官方历史需重新核验。通知claim通过IDB事务去重，交付失败不宣称已送达。
- 全部浏览器集成使用localhost或被拦截的合成学校页面，未产生生产预约/取消/签到/暂离。

残余风险：本机存储不加密；有本机账户权限的人可读取。学校页面扩展DOM是观察证据，不是防篡改证明。第三方扩展或用户开发者工具可改DOM。当前网页结构变化可能导致拒绝解析。操作系统可限制通知。未作渗透测试或第三方安全认证。旧脚本中环境凭据登录路径不由本产品调用，不应作为日常命令运行。
