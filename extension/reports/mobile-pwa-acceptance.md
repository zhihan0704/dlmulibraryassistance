# 手机PWA验收 1.0.0

实现手机优先、桌面响应式的预约首页、预约详情、签到准备、历史、设置、导入页面。支持有效期/字段/时间校验、QR URL fragment导入并立即清除、系统相机扫码和支持BarcodeDetector时的内置相机、JSON导入与完整备份、IndexedDB六表、旧手机数据库迁移、倒计时、用户提醒偏好、通知授权、去重、ICS和安装图标。

Service Worker构建时预缓存页面入口及带hash的资源，按内容版本更新缓存；离线打开已缓存界面和本机数据库通过测试。旧库保留不删除。第三方/备份的官方结论仅作为未核验历史，不能获得OFFICIAL_CONFIRMED。

证据evidence/mobile-e2e.json：本机Edge模拟390×844和1280×900，测试fragment导入、刷卡报告不等于官方、刷新恢复、完整备份到另一浏览器配置、过期拒绝、旧库迁移、离线重新打开和无水平溢出。截图mobile-home.png、mobile-desktop.png。不是Android/iPhone实机、摄像头扫码、主屏幕安装或后台通知送达测试。

未部署公网网址。交付mobile-pwa.zip可部署到用户控制的HTTPS静态站点，无需账号和后端API；部署后电脑填写该URL即可交接。手机不会继承电脑登录。后台运行受系统限制，不能承诺始终送达，ICS须用户导入日历并核对提醒设置。手机端显示交接时的快照，不声称实时跨设备同步或独立取得官方确认。
