# DLMU Library Assistant 1.0.0

电脑管理预约、手机查看与提醒，本人携带校园卡到学校机器刷卡。软件不代替刷卡，不提交预约、取消、暂离或签到。

## 下载和安装

发布包包括 Edge 可加载扩展、Mobile PWA 静态构建、源码、SHA256 和测试报告。解压扩展包，在 `edge://extensions` 启用开发者模式，选择“加载解压缩的扩展”。请手动确认权限：storage、alarms、sidePanel、activeTab、notifications，以及唯一学校座位域名。点击工具栏图标打开侧边栏。安装新权限版本可能需要手动重新启用扩展。

正常使用不需要 Playwright，不创建第二套登录环境。使用你日常 Edge 中正常登录的学校网页，进入个人中心的“个人预约”。内容脚本自动读取可识别的完整可见记录；也可点“读取官方个人预约”。编号截断、表头缺失或冲突时拒绝猜测。源码中的历史研究脚本不属于日常流程，不运行其自动登录功能。

## 桌面签到准备

选中预约后，系统按你设置的提醒提前时间创建本地任务（默认20分钟是用户偏好，不是学校规则）。携带校园卡，到现场官方机器本人刷卡，再点击“本人已在机器刷卡”。这只生成本人报告，界面保持等待官方核验。重新打开学校个人预约页：只有同一完整预约显示“已签到”“签到成功”或“使用中（已签到）”才保存明确文字确认；审核通过、1027/1029/1093、位置或颜色不等于签到成功。

官方签到窗口与最短时长等历史规则存在冲突，1.0.0继续标为UNKNOWN/NEEDS_REVIEW，不推断可预约资格。座位地图、搜索、本机收藏、历史快照和模拟任务保留在“座位地图、历史数据与研究工具”折叠区。历史152座位采集时间为2026-11-01，不冒充实时数据。

## 手机交接

将 `mobile-pwa` 包中的全部文件部署到你控制的 **HTTPS静态站点**，保留相对目录。无需服务端账号、数据库或云API。当前交付没有替你部署到公网，也没有预置手机网址。电脑侧边栏填写该HTTPS地址，生成二维码；二维码完全本地绘制。手机系统相机扫码打开后，数据经验证写入IndexedDB，地址栏导入片段立即清除。也可导出交接JSON并在手机导入。

Android浏览器菜单选择安装/添加主屏幕；iPhone使用Safari分享→添加到主屏幕。首次联网打开并完成缓存后，可以离线查看已导入预约和本人记录。相机扫描入口依赖BarcodeDetector，缺少支持时使用系统相机或JSON文件。电脑与手机数据库独立，不共享Cookie，不实时同步。二维码/JSON为未签名交接数据，不能给手机授予官方确认信任。

## 提醒和备份

桌面使用Chrome Alarms和系统通知；浏览器关闭或系统暂停时不保证准点。手机只在系统允许网页运行时检查提醒，操作系统可能暂停后台PWA。请同时导出ICS并在系统日历中确认导入和提醒权限；日历送达也受系统设置影响。

完整JSON备份含任务、事件、快照、偏好和通知历史及SHA256完整性摘要。恢复保留本人刷卡报告，但导入的官方结论变成待重新核验的历史。摘要用于发现损坏，不是官方签名。旧版手机数据库自动迁移并保留原库；也支持旧版JSON。原始快照不覆盖，默认不自动删除历史；请定期导出备份，浏览器清除站点数据会删除本机存储。

## 登录与恢复

扩展只使用当前浏览器页面。离开业务域或进入SSO时停止该页面的数据读取，保留任务；域名提示仅在浏览器提供URL时可用，不单凭进程存活判断登录。用户人工登录后返回个人预约，新的页面观察重新匹配身份并更新任务。重启/Worker重建后认证视为UNKNOWN，已有官方确认仅作为历史证据保留。学校服务器会话期限无法由扩展延长，软件不承诺永久登录。

## 本地开发

`npm ci` 安装锁定依赖；`npm run verify` 运行单元测试、严格类型检查、两端构建和扩展校验。`npm run test:product`、`npm run test:mobile`、`npm run test:extension-product` 运行真实Edge+本地合成数据集成测试。`npm run test:e2e`及`npm run test:restart`保留历史回归。默认在Windows官方Edge路径，可设置EDGE_PATH。测试独立配置用于验证，不作为产品登录环境。

`npm run serve:mobile`只启动本机预览 http://localhost:4173，不对局域网开放，也不能替代手机HTTPS托管。
